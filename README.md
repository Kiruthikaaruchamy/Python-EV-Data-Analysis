# Electric Vehicle Data Analysis using Python

## Project Overview

This project performs exploratory data analysis on electric vehicle data using Python. The analysis focuses on understanding vehicle characteristics, battery types, performance metrics, and relationships between key variables.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

1. Performed exploratory data analysis to understand the characteristics of electric vehicles and identify data inconsistencies.
2. Cleaned and prepared the dataset by handling missing values, duplicate records, and inconsistent data.
3. Used Pandas and NumPy to analyze relationships between vehicle performance variables and battery types.
4. Calculated descriptive statistics to summarize key numerical variables.
5. Analyzed the relationship between top speed and battery type.
6. Created visualizations using Matplotlib and Seaborn to identify trends and patterns in the dataset.
7. Examined key electric vehicle attributes such as battery capacity, range, efficiency, acceleration, and top speed.
8. Derived business insights from the analysis to support understanding of electric vehicle characteristics and market trends.

## Files

- `EV_Data_Analysis.ipynb` – Python analysis, data cleaning, exploratory analysis, visualizations, and insights.
- `EV_Data_Dataset.csv` – Dataset used for the analysis.
